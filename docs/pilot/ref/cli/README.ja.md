# コマンド

[English](README.md) | 日本語

**ワークスペースには、Agent Fleet 独自のコマンドが入っています。** どれもターミナルからもエージェントからも使えます。

| コマンド | できること |
|---|---|
| [af-aws-exec](af-aws-exec.ja.md) | AWS プロファイルの権限で、コマンドを 1 つ実行する |
| af-gcloud-exec | Google Cloud プロファイルの権限で、コマンドを 1 つ実行する |
| af-db | テスト用の PostgreSQL / MySQL をワークスペースの中で動かす |
| af-memory | エージェントメモリの変更履歴を見る・ほかのメモリから取り込む |
| af-scratch | ビルドの出力を、速い作業用ディスクに移す |
| af-arch-repair | CPU アーキテクチャが変わったあと、自分で入れたツールを入れ直す（ふつうは自動で実行されます） |

> [!NOTE]
> パイロット版です。今は af-aws-exec のページだけがあります。

どのコマンドも `--help` で使い方を表示します。
