# MCP ツール

[English](README.md) | 日本語

**Agent Fleet は、エージェントやアシスタントが Agent Fleet 自体を操作するための MCP ツールを用意しています。**
同じツールでも、どこから使うかによって見えるものが違います。

## どこで使えるか

| 列 | 使う人 | つなぎ方 |
|---|---|---|
| セッション | セッションの中のエージェント | 自動でつながります（MCP サーバー名は `af`） |
| アシスタント | Console のアシスタント | 自動でつながります。「読み取り」は常に、「書き込み」は書き込みを許可した会話だけで使えます |
| 外部 MCP | Agent Fleet の外にあるクライアント（claude.ai、ChatGPT、別の PC の Claude Code など） | Control Plane の `/mcp` に、アクセストークンか OAuth でつなぎます。[ワークスペースを外から使う](../../member/19-outside-access.ja.md) を参照 |

「使える場所」のセッションに「」付きのスイッチ名があるツールは、**⚙設定 →「エージェント」** のそのスイッチをオンにしたときだけ使えます。
「エージェントメモリ」は **⚙設定 →「エージェントメモリ」** にあります。

| スイッチ | 既定 |
|---|---|
| セッションからのセッション起動 | オフ |
| セッション間メッセージ | オフ |
| 過去セッションの検索 | オン |
| 画像生成 | オフ |
| エージェントメモリ | オフ |

ほかにも、次のような条件があります。

- ブラウザ（Chromium）のツールは、ブラウザの無いワークスペース（Kubernetes・AWS ECS）では出ません。
- 外部 MCP で使えるツールは、アクセストークンの権限（読み取り・書き込み）で変わります。「管理者」のツールは、テナント管理者とスーパー管理者にだけ見えます。

> [!NOTE]
> パイロット版です。この一覧は、ツールの定義から作った下書きです。


## 完了と停止

| ツール | できること | 使える場所 |
|---|---|---|
| `af_report` | 渡された指示が完全に終わったことを一度だけ報告する（`[agent-fleet]` 付きの指示向け） | セッション |
| `af_stop_after_turn` | このターンの終わりに自分自身を停止するよう予約する／解除する | セッション |
| `propose_session_handoff` | 続きの作業用の新しいセッションの最初のプロンプトを利用者に提案する（自分では何も起動しない） | セッション |

## セッションを見る

| ツール | できること | 使える場所 |
|---|---|---|
| `list_my_sessions` | ワークスペースのセッション一覧（名前・種別・状態・作業ディレクトリ）を返す | アシスタント（読み取り）<br>外部 MCP |
| `get_session_status` | セッションの今の状態（作業中・待機中・質問中・プラン待ち）と保留中の質問を返す | セッション<br>アシスタント（読み取り）<br>外部 MCP |
| `get_session_output` | セッションの最近の端末出力を読む（前回の続きから） | セッション（「セッションからのセッション起動」（自分の子だけ））<br>アシスタント（読み取り）<br>外部 MCP |
| `get_session_usage` | セッションごとのコンテキスト使用量と累積トークン消費を返す | セッション<br>アシスタント（読み取り）<br>外部 MCP |
| `get_agent_usage` | 各エージェントCLIのサブスクリプション使用量とレート制限を返す | セッション（「セッションからのセッション起動」）<br>アシスタント（読み取り）<br>外部 MCP |
| `search_sessions` | 過去のセッション（停止・アーカイブ含む全エージェント）の会話を全文検索する | セッション（「過去セッションの検索」） |

## セッション・子セッションを起動して操作する

| ツール | できること | 使える場所 |
|---|---|---|
| `create_session` | 新しいセッションを起動して最初の作業を渡す（子セッションの起動） | セッション（「セッションからのセッション起動」）<br>アシスタント（書き込み）<br>外部 MCP |
| `list_child_sessions` | 自分が起動した子セッションの一覧（状態・残り枠）を返す | セッション（「セッションからのセッション起動」） |
| `rename_child_session` | 自分が起動した子セッションのタイトルを付け直す | セッション（「セッションからのセッション起動」） |
| `list_repos` | ワークスペース内のgit作業コピー（~/repos）の一覧を返す | セッション（「セッションからのセッション起動」）<br>アシスタント（読み取り）<br>外部 MCP |
| `list_models` | エージェント種別ごとに今選べるモデルの一覧を返す | セッション（「セッションからのセッション起動」）<br>アシスタント（書き込み）<br>外部 MCP |
| `send_to_session` | 指定セッションにプロンプトを送って実行させる（停止中なら再開してから） | アシスタント（書き込み）<br>外部 MCP |
| `answer_session_question` | セッションが出している質問に選択肢で答える | アシスタント（書き込み） |
| `respond_session_plan` | セッションが承認待ちのプランを承認／却下する（claudeのみ） | アシスタント（書き込み） |
| `stop_session` | セッションを停止する（会話と作業コピーは残り再開できる） | セッション（「セッションからのセッション起動」（自分の子だけ））<br>アシスタント（書き込み）<br>外部 MCP |
| `stop_session_after_turn` | 今のターンが終わったら止まるよう予約する（中断しない） | セッション（「セッションからのセッション起動」（自分の子だけ））<br>アシスタント（書き込み）<br>外部 MCP |
| `resume_session` | 停止中のセッションを会話を保ったまま再開する | セッション（「セッションからのセッション起動」（自分の子だけ））<br>アシスタント（書き込み）<br>外部 MCP |

## セッション間メッセージ

| ツール | できること | 使える場所 |
|---|---|---|
| `list_peer_sessions` | 同じワークスペースの他のセッション一覧を返す（自分は除く） | セッション（「セッション間メッセージ」） |
| `send_to_peer_session` | 他のセッションに短いメッセージを送る（停止中なら再開して届く） | セッション（「セッション間メッセージ」） |
| `peek_session_output` | 他のセッションの最近の出力を読み取り専用で見る | セッション（「セッション間メッセージ」） |

## 掃除

| ツール | できること | 使える場所 |
|---|---|---|
| `list_cleanup_candidates` | 溜まったセッション・worktreeの掃除候補を点検して返す | アシスタント（読み取り）<br>外部 MCP |
| `list_cleanup_archives` | 掃除で退避したアーカイブの一覧を返す | アシスタント（読み取り）<br>外部 MCP |
| `archive_session` | 終わったセッションをアーカイブして一覧から隠す（復元可） | アシスタント（書き込み）<br>外部 MCP |
| `delete_worktree` | 不要なworktreeを削除する（未コミット／未pushがあると拒否） | アシスタント（書き込み）<br>外部 MCP |
| `delete_session` | セッションを完全に削除して容量を回収する（退避アーカイブから復元可） | アシスタント（書き込み）<br>外部 MCP |
| `delete_branch` | マージ済みのローカルブランチを削除する | アシスタント（書き込み）<br>外部 MCP |
| `restore_cleanup_archive` | 退避したアーカイブからセッション／ブランチを復元する | アシスタント（書き込み）<br>外部 MCP |
| `purge_cleanup_archive` | アーカイブを完全削除する（復元不可） | アシスタント（書き込み）<br>外部 MCP |

## エージェントメモリ

| ツール | できること | 使える場所 |
|---|---|---|
| `memory_index` | 共有メモリ（全エージェント共通）の一覧を返す（本文なし） | セッション（「エージェントメモリ」）<br>外部 MCP |
| `memory_search` | 共有メモリを全文検索する | セッション<br>外部 MCP |
| `memory_read` | 共有メモリを1件、本文付きで読む | セッション<br>外部 MCP |
| `memory_save` | 共有メモリを新規作成／更新する（即公開。秘密情報は拒否） | セッション<br>外部 MCP |
| `memory_forget` | 共有メモリを公開から外す（履歴は残る） | セッション<br>外部 MCP |
| `memory_projects` | メモリのプロジェクト一覧（id・リポジトリ・件数）を返す | 外部 MCP |

|---|---|---|
