# 主な用語

[English](concepts.md) | 日本語

**覚えておけばいいのは 6 つだけです。** 外側から順に並べると、それぞれの関係がつかみやすくなります。

```
テナント（チーム）
└─ あなたのワークスペース（専用の作業環境）
   ├─ リポジトリ（作業コピー / worktree）
   └─ セッション（1 つの仕事）＝ エージェント × 実行方式
```

## テナント

部署やチームの単位です。テナントが違うメンバーからは、お互いの作業は見えません。
ほとんどの人は 1 つだけに所属しています。

## ワークスペース

**あなた専用の作業環境**です。リポジトリも、作業途中のファイルも、セッションもここに入ります。
止めても中身は消えません。しばらく使わないと自動で止まります。

## リポジトリ（作業コピー・worktree）

ワークスペースにクローンした git リポジトリです。同じリポジトリの作業コピーを
**worktree** として複数作れるので、何本ものセッションに並行して作業させてもぶつかりません。

## セッション

**1 つの仕事**です。エージェントとの会話、作業する場所、実行中かどうかの状態をひとまとめにしたもの。
止めても一覧に残り、あとからクリックで再開できます。

## エージェント

実際に作業する AI です。Claude Code、Codex など、CLI のコーディングエージェントを指します。
使う前に一度、[接続](../../member/09-agents.ja.md)（ログイン）しておきます。

## 実行方式

エージェントを動かす経路のことで、2 種類あります。

- **マネージド**：チャット画面でやり取りします。端末は開きません。
- **ターミナル（CLI）**：エージェント自身の画面を端末で直接操作します。

> [!TIP]
> **「サインイン」と「ログイン」は使い分けています。** Agent Fleet 自体に入るのが「サインイン」、
> claude や gcloud などの外部の CLI・サービスに入るのが「ログイン」です。

ほかの用語は [用語集](../../ref/glossary.ja.md) にあります。
