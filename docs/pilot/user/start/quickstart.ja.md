# クイックスタート

[English](quickstart.md) | 日本語

**サインインして、最初のセッションでエージェントに仕事を頼むところまで進めます。**

はじめてのときは、ホームに **「Agent Fleet へようこそ」** カードが出ます。
以下の手順はそのカードと同じ流れなので、カードのボタンを上から押していってもかまいません。

## 1. サインインする

Console の URL を開いて、会社のアカウントでサインインします。
ボタンがいくつか並んでいるときは、管理者から案内された方法を選んでください。

## 2. ワークスペースを起動する

ようこそカードの **「起動」** を押します。表示が「起動中…」から「稼働中」に変われば完了です。
**これが終わるまで、ほかの操作はできません。**

## 3. エージェントを接続する

**「接続」** を押して、使いたいエージェントにログインします。1 つ接続すれば先に進めます。
チームの既定のエージェントが決まっていれば、カードにその名前が出るので、まずはそれを選んでください。

## 4. リポジトリをクローンする

ワークスペース操作バーの **「はじめる」** から、リポジトリを選ぶ（または URL を貼る）と、
クローンとセッションの起動をまとめてやってくれます。

private リポジトリを使うときは、先に **⚙設定 →「Git ホスティング」** で
GitHub / Bitbucket にログインしておきます。

> [!TIP]
> コードを書かずに質問や翻訳だけしたいときは、ようこそカードの **「チャットをはじめる」** を選びます。
> git もターミナルも要りません。→ [チャットとメモ](../../member/10-chat-memo.ja.md)

## 5. エージェントに仕事を頼む

セッションが開いたら、やってほしいことを書いて送ります。
質問されたときや、許可・プランの承認を求められたときは、ホームの **「あなたの返事を待っています」** に並びます。

## 一日の終わりに

ワークスペースは **止めてもかまいません**。止め忘れても、しばらくすると自動で止まります。

- リポジトリと、コミットしていない変更も残ります
- セッションは「停止中」として残り、次回クリックで再開できます
- エージェントや git のログインも残ります

> [!CAUTION]
> **ワークスペースの外に残るのは、push した分だけです。** 大事な変更はこまめにコミットして push しておきましょう。
