# 資格情報の扱い

[English](credentials.md) | 日本語

**Agent Fleet がつなぐ外部サービスのログイン情報が、どこに置かれ、誰が使えるかをまとめたページです。**

> [!NOTE]
> パイロット版です。今は AWS の項目だけで、エージェント・git・Google Cloud なども、このページに順に追加していきます。

## AWS

- **AWS の秘密情報は Agent Fleet に保存されません。** Console に保存されるのは、プロファイルの設定（ポータル URL・アカウント・ロールなど）だけです。
- ログインはブラウザでコードを承認する方式で、手に入るのは**短命の資格情報**です。これはあなたのワークスペースの中にだけ置かれます。
- コンテナ（Docker / AWS ECS）で動くワークスペースでは、セッションとターミナルにワークスペース自身の AWS 権限は渡りません（AWS ECS では、管理者が設定で戻した場合を除きます）。AWS を使うときは、あなたのプロファイルを `af-aws-exec` で明示して使います。
- `af-aws-exec` での実行は、どのプロファイル・アカウント・ロールで動いたかがセッションの会話に残ります（コマンドの引数は記録されません）。ただし、これは何が動いたかを確かめるためのもので、監査ログではありません。

使い方は [AWS SSO を使う](../integrations/aws-sso.ja.md) を見てください。
